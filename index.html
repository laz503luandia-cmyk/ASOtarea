Información Básica de Arquitectura

Pilares fundamentales para la administración moderna de sistemas operativos en red.

🛡️

Active Directory (AD DS)

Permite estructurar Unidades Organizativas (UO), gestionar cuentas de usuarios por grupos de trabajo y delegar permisos granulares evitando accesos no autorizados entre departamentos.

🌐

Internet Information Services (IIS)

Servidor web de alto rendimiento nativo en Windows Server capaz de alojar múltiples directorios virtuales y aplicaciones web accesibles de forma local o pública.

💻

Protocolo RDP & Git

Conexión remota mediante el puerto 3389 para administración simultánea, combinada con repositorios de Git para desplegar código directamente en producción.

Problemas Comunes y Soluciones

Guía rápida de resolución de incidentes en entornos de servidores compartidos.

⚠️ Problema Detectado

Modificación accidental de archivos ajenos

En servidores compartidos, múltiples usuarios conectándose por RDP pueden alterar o borrar por error las carpetas de otros equipos de trabajo.

✅ Solución Implementada

Delegación por Unidades Organizativas (UO)

Configurar permisos NTFS estrictos vinculados a cada grupo de Active Directory para que cada integrante solo tenga escritura en su propio espacio.

⚠️ Problema Detectado

Subcarpetas duplicadas al clonar con Git

Al ejecutar un git clone convencional dentro del directorio del usuario en IIS, se crea una carpeta extra que rompe la ruta directa del archivo index.html.

✅ Solución Implementada

Clonación directa en el directorio raíz personal

Clonar el repositorio indicando el directorio actual o estructurar el repositorio con el archivo index.html en la raíz para que IIS lo resuelva de inmediato.

⚠️ Problema Detectado

Bloqueo de sesiones remotas por inactividad

Las sesiones abiertas sin cerrar consumen memoria RAM y CPU en la máquina virtual del servidor, degradando el rendimiento para el resto de la clase.

✅ Solución Implementada

Cierre ordenado de sesión RDP y políticas GPO

Finalizar la sesión al terminar el despliegue en IIS y aplicar políticas de desconexión automática para sesiones inactivas en el servidor.
